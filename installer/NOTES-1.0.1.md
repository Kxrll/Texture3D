## Substance 3D Painter s’installe automatiquement

Si Painter est détecté, l’installateur copie son plugin dans le profil Windows courant. Il se charge au prochain lancement de Painter, sans activation dans le menu Python. Si Painter a été installé après Texture3D, relancer l’installateur.

Fermer Blender et Photoshop, puis lancer **Texture3D-Setup-1.0.1.exe**. Pour une mise à jour depuis 1.0.0, les projets et la configuration sont conservés. Si Painter est ouvert, le relancer après l’installation.

Les [instructions d’installation manuelle](https://github.com/Kxrll/Texture3D/blob/v1.0.1/docs/PAINTER.md) restent disponibles pour une installation de Painter non détectée. Les archives **Source code** contiennent les sources de cette version. **SHA256SUMS.txt** permet de vérifier l’installateur Windows non signé.
