# Texture3D Studio 1.0

Première version officielle pour Windows x64.

- Peinture dans Photoshop et aperçu 3D actualisé à chaque Ctrl + S.
- Un document commun et les UV d’origine de Blender.
- Sélection des pièces avec leur maillage, isolation et repérage UV.
- Retour de la texture vers Blender ou envoi dans la Base Color de Substance 3D Painter.
- Reprise du projet Substance existant en choisissant son fichier .spp depuis le viewer.

**Texture3D-Setup-1.0.0.exe** installe ou met à jour Texture3D Studio, son extension Blender et le plugin Photoshop. Le plugin Substance est facultatif. Son activation est décrite dans le [guide Painter](https://github.com/Kxrll/Texture3D/blob/v1.0.0/docs/PAINTER.md).

Fermer Blender et Photoshop avant de lancer l’installateur. Il conserve les projets et la configuration de l’installation précédente. L’exécutable Windows n’est pas signé.

Les archives **Source code** de GitHub contiennent les sources exactes de cette version. **SHA256SUMS.txt** permet de vérifier l’intégrité de l’installateur.
