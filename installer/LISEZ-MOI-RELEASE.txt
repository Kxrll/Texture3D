TEXTURE3D STUDIO 1.0.1 — INSTALLATION WINDOWS

1. Fermer Blender et Photoshop.
2. Lancer Texture3D-Setup-1.0.1.exe. L’installateur détecte les applications
   et installe le plugin Photoshop via Adobe Creative Cloud Desktop.
3. Dans Blender, sélectionner le modèle, ouvrir le panneau latéral avec N,
   puis choisir Texture3D > Peindre dans Photoshop.
4. Enregistrer dans Photoshop avec Ctrl + S pour mettre à jour le viewer.

Pour mettre à jour une ancienne version, relancer l’installateur au même
emplacement. Les projets et la configuration locale sont conservés.
L’installation est faite dans le compte Windows courant. L’exécutable
n’est pas signé et les règles Windows ou Adobe peuvent en limiter l’usage.

SUBSTANCE 3D PAINTER (FACULTATIF)

Si Painter est détecté, son plugin est installé pour ce compte Windows.
Il se charge à la prochaine ouverture de Painter.

Si Painter a été installé après Texture3D, relancer l’installateur ou
ouvrir Python > Plugins Folder et copier le chemin. Fermer Painter,
puis exécuter depuis PowerShell :

Set-Location (Join-Path $env:LOCALAPPDATA 'Programs\Texture3D')
powershell.exe -NoProfile -File .\INSTALLER_PAINTER.ps1 -PluginsDirectory "CHEMIN\python\plugins"

Relancer Painter. Si nécessaire, activer Python > texture3d_painter.
Enregistrer le projet Substance au format .spp pour le reprendre ensuite.

Guide, sources et assistance : https://github.com/Kxrll/Texture3D
